# Roadmap moved to GitHub

Active and future work is tracked in **GitHub Issues** and the repository **Project** rather than duplicated in a Markdown status checklist.

- [Browse Issues](https://github.com/petaurora/kink-profile/issues)
- Use the repository Project for the visual **Now / Next / Later** view.
- Pull requests should link or close the Issues they implement.

This file remains only so older links do not break. It intentionally does **not** duplicate current milestone status, priority, or acceptance checklists.

## Where information belongs

- **Current product behavior / technical contracts:** repository documentation and code
- **Actionable work:** GitHub Issues
- **Priority / status / sequencing:** GitHub Project
- **Private strategy, research, monetization, and early exploration:** private product workspace
- **Historical implementation:** closed Issues/PRs and git history

See [Documentation](docs/README.md) for the durable product, data, scoring, and feature contracts that remain versioned with the code.
